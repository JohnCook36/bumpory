# Bumpory Design System v0.1

## Brand direction
- Personality: gentle, calm, private, practical. Never use alarmist language.
- Wordmark: **bumpory.** (lowercase and terminal dot); slogan: *Every week, a little story.*
- Mark: two-heart-inspired abstract form, see `assets/brand/bumpory-mark.svg`. **Concept**, not production launcher PNG.
- Visual style: clean cream surfaces, soft plum accents, rose and sage functional accents, rounded cards and legible typography. No mandatory gendered palette.
- Language: Russian-first; brand name in English. No clinical judgments without expert review.

Typography: dynamic system fonts, 16px body / 24px line-height, 20px section, 32px hero. Touch targets >= 48pt. Radius: 12, 18, 24, 32. Spacing: 4, 8, 12, 16, 24, 32.

## Screens in first vertical slice
1. Onboarding: last menstrual period date, estimated term explanation, local-only privacy notice.
2. Today: actual gestational age, estimated due date, one practical task and navigation.
3. Weeks: 1–42 navigator, editorial draft content visibly marked unreviewed.
4. Journal: notes, one photo per entry, review and deletion, stored offline.
5. Plan: stable per-week checklists with persisted completion.
6. Help: emergency contact shortcuts; no symptom triage or diagnosis.

## Accessibility
- Semantic buttons, labels, large text, high contrast on primary CTA.
- Avoid information conveyed by color alone.
- No animations necessary to read or act.
